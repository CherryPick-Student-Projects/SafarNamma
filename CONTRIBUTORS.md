## 🤝 How You Can Contribute

We welcome contributions of all kinds from developers and explorers alike!

- 🐛 **Bug Reports & Feature Requests**: Found a glitch or have an idea? [Open an issue](https://github.com/shahkavya23/SafarNamma/issues).
- 💻 **Code Contributions**: Frontend (React + Vite + Tailwind) and Backend (FastAPI + SQLite/Supabase). Check the [Good First Issues](README.md#-good-first-contributions) in our README.
- 📍 **Curate Hidden Gems**: Suggest or add authentic Karnataka destinations and itineraries that guidebooks miss.
- 🎨 **Design & UX**: Help refine accessibility, animations, responsive layouts, or contribute authentic photography.
- 📝 **Documentation**: Improve README, API documentation, comments, and setup guides.

---

## 🚀 Getting Started

1. Check out our **[Contributing Guide](README.md#-contributing-in-5-steps)** in the main README.
2. Fork the repository and create a feature branch (`git checkout -b feat/your-feature-name`).
3. Commit your changes following our commit conventions (`feat:`, `fix:`, `style:`, `docs:`, `refactor:`).
4. Push to your branch and open a Pull Request!

Once your PR is merged, your profile will automatically appear on the [Contributor Wall](https://github.com/shahkavya23/SafarNamma/graphs/contributors)!
